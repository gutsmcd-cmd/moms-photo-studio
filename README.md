# Mom's Photo Studio

A simple, free photo editor for the phone. No ads, no login.

Live: https://gutsmcd-cmd.github.io/moms-photo-studio/

Fix (crop, turn, brighter/darker, color filters, red eyes, remove things, blur background, sharper), Add (words, shapes, another picture with cut-out), Style (paint my photo in a style), Done (save, share, print).

Remove things (LaMa), Sharper (Real-ESRGAN) and cut-outs (RMBG-1.4) run on the phone. "Paint my photo in a style" tries free Hugging Face Spaces (FLUX.1 Kontext, then Qwen Image Edit); if they are busy, a simple painter on the phone is offered instead.
